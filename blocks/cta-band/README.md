# cta-band

Custom **hero** block. Purpose: cta.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: heading + CTA link (whole band linked).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.

## Content structure

| CTA Band |
| --- |
| Heading containing (or followed by) the target link |

1 row x 1 cell. The whole band is clickable when a link is present.
