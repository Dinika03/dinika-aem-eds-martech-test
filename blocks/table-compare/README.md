# table-compare

Custom **table** block. Purpose: comparison.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: header row + label column + 2 product columns.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.

## Content structure

| Table Compare | | |
| --- | --- | --- |
| (empty) | Product A (link) | Product B (link) |
| Row label | value | value |

Row 1 is the header row; in every following row the first cell is the row label. Any number of rows/columns.
