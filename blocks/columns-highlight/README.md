# columns-highlight

Custom **columns** block. Purpose: feature.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: image + heading + paragraphs + list.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.

## Content structure

| Columns Highlight | |
| --- | --- |
| image | H2 heading, paragraphs, bullet list |

1 row x 2 cells. The image always renders on the left on desktop.
