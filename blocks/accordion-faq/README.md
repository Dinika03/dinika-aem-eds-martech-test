# accordion-faq

Custom **accordion** block. Purpose: faq.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: question | answer x5.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.

## Content structure

| Accordion Faq | |
| --- | --- |
| Question | Answer (rich text) |

One row per question. Items render as native details/summary elements, collapsed by default.
